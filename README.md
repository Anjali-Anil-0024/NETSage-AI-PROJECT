# NETSage-AI

## AI-Powered Network Security & Log Analysis System

NETSage-AI is an AI-assisted cybersecurity project designed to analyze network security cases, review logs, diagnose potential security issues, and provide rule-based security recommendations.

## Features

- Security case analysis
- AI-assisted diagnosis
- Log review and analysis
- Rule-based security checking
- Automated diagnosis prompts
- Structured security data
- Python-based implementation
